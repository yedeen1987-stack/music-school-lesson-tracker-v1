## 通知

- 完成本节后记录“课程完成通知”，内容包含剩余课时。
- 管理员可在“基础设置”中设置余额提醒，例如 `10,7,5,3,1`。
- 当余额刚好到设置的数字，会记录“课时余额提醒”。
- 当前 Cloudflare 版先完整写入通知日志，真正发邮件需要后续接入 HTTP 邮件服务。
